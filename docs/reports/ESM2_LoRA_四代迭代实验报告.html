4关键错题本归因与方法论沉淀

  • 发现 1（v1 错题本）：快捷特征陷阱 — Top-10 假阳性全部以 L 结尾，人类正常泛素 TLTGKTITL 误报至 0.933。证明仅用随机正常蛋白做负样本会让模型走“看 C 端疏水残基”捷径。
  • 发现 2（v2 消融）：去偏必须正负对称 — 仅对正样本限制 L 结尾占比而不限制负样本，会引入反向偏差，导致 Hard AUROC 下跌至 0.522；同时乱序对照与低复杂度陷阱的引入被证明极其有效（陷阱均分直降 74%，长度偏差归零）。
  • 发现 3（v3 → v3.5）：任务解耦决定天花板 — 把“pMHC 结合（随机负样本）”和“结合后 T 细胞激活（实测阴性负样本）”拆成两阶段训练，既保留了 `+0.205` 的 HLA 结合特异性，又在仅 1 个 Epoch 内把纯实验 Hard AUROC 从 `0.685` 拉到 `0.717`（独立留出集同步提升 `+0.044`）。

5下一阶段（v4 冲分路线图）

v4 目标：突破数据量与单折方差瓶颈，将独立留出集 Hard AUROC 冲向 0.68–0.75+，验证集纯实验 AUROC 冲向 0.76+。
  • 数据扩容 + 引入 CEDAR 癌症表位专库：合并 query-api.cedar.iedb.org 纯肿瘤/新抗原实测数据，并将每个 HLA 等位基因采样上限从 350 扩充至 800+；同时加入 HLA 错配负样本 强化结合槽特异性。
  • 完整 5 折两阶段训练 + 5 折集成（5-Fold Ensemble）：不再只用单折 fold_0，对 5 折最优权重做概率均值集成，进一步降低方差并压低校准误差 ECE。
  • 工程合入预备：待 v4 体检达标后，作为零侵入可选插件 epitoperank/peptide/esm2_scorer.py 接入 EpitopeRank，与现有 IEDB / MHCflurry 呈递分形成“结合 + 免疫原性”双引擎互补。
