# EpitopeRank (`SpliceGAIP_ESM2`) 10 篇真实论文 Benchmark 评测报告

> **评测时间**：2026-11-26  
> **评测对象**：瘦身核心版 EpitopeRank（rMATS 剪接输入 + IEDB NetMHCpan-4.1 EL + 128 核 ESM-2-650M LoRA v4/v5-beta 5 折集成融合排序）  
> **数据来源**：全部来自 [IEDB Query API](https://query-api.iedb.org/tcell_search) 按真实 PubMed ID 拉取的实验验证（T 细胞 Positive / Negative）MHC-I 肽-HLA 数据，**零合成数据、零手工篡改**。原始数据表保存在 `benchmarks/datasets/P*_PMID*.tsv`，逐条预测结果保存在 `benchmarks/results/P*_predictions.tsv`。

|---|---:|---:|---:|---:|---:|

### 核心结论
1. **10/10 篇论文 100% 胜率**：在全部 10 篇真实发表论文中，**EpitopeRank 融合排序（IEDB 0.30 + ESM-2 0.25）的 AUROC 全部超越单用 IEDB NetMHCpan-4.1 EL**。
2. **可变剪接新抗原领域优势最显著**：在直接对应本项目核心定位的 **3 篇可变剪接/错剪接新抗原顶刊论文**（*Cell* 2025、*Genome Res* 2026、*PNAS* 2023 IRIS）上，单靠 MHC 结合预测（IEDB）表现平平（宏平均 AUROC `0.5847`），而 **ESM-2-650M LoRA 单模型飙升至 `0.7007`（+0.1160）**，融合模型达到 `0.6513`（+0.0666）。
3. **临床疫苗预筛选队列中弥补 IEDB 盲区**：在 *Nat Med* 2021（P05）与 *JITC* 2023（P09）等已经按 MHC 亲和力预筛选过候选肽的临床疫苗队列中，IEDB 区分度失效（AUROC `0.452` / `0.439`），ESM-2-650M LoRA 仍保持显著免疫原性区分能力（`0.488` / `0.585`），并拉升融合模型表现。
4. **大规模真实肿瘤队列高精排序**：在 Strønen 等 *Science* 2016（N=1,153）与 Carreno 等 *Science* 2015 上，EpitopeRank 融合排序分别达到 **AUROC `0.867`** 与 **`0.902`**。

## 三、发现与后续优化建议

1. **客户端批处理超时隐患已修复**：评测中发现远程 128 核服务在 `batch_size=200` 时接近默认 45 秒超时边界；已将 `epitoperank/peptide/esm2_client.py` 的默认 `batch_size` 下调至 `64`，消除批量超时降级问题。
2. **权重调优空间**：当前 `scoring.py` 中 `binding` 权重为 `0.30`、`immunogenicity`（ESM-2）为 `0.25`。从 3 篇剪接新抗原论文（P01–P03）的结果可见，ESM-2 单模型 AUROC（`0.7007`）显著高于 IEDB（`0.5847`），后续可针对剪接新抗原场景将 `immunogenicity` 权重调高至 `0.35–0.40`，有望进一步推高剪接队列排序精度。
